# સત્સંગ બોક્સ

Gujarati satsang games, one link (hub page `index.html`), each game in its own folder.

| # | Folder | ગેમ |
|---|--------|-----|
| 1 | `prashn-leela/` | સત્સંગ પ્રશ્ન (નામ પેટી, પાંચ બોક્સ) |
| 2 | `dhyan-murti/` | ધ્યાન દર્શન (ધ્યાન મૂર્તિ ગેમ) |
| 3 | `antahshatru-vijay/` | અંતઃશત્રુ વિજય |
| 4 | `fal-ful-memory/` | ફળ ફૂલ મેમરી ગેમ |

દરેક ફોલ્ડરમાં `index.html` (ગેમ) અને `SOURCE.md` (ચર્ચા, નિર્ણયો, બાકી કામ, તારીખ-સમય સાથે).
ફેરફાર કરવા: ગેમનો નંબર કે નામ આપો, ગેમ ફાઇલ અને SOURCE.md સાથે અપડેટ થશે.

**ડિઝાઇન:** આખા હબ અને ચારેય ગેમમાં એક જ માટી (ક્લે) સ્ટાઇલ — રંગ-યાદી `clay.css` માં (ક્રીમ ટાઇલ, ટેરાકોટા બટન, ઓલિવ લીલો, ભૂરો ટેક્સ્ટ). નીચેનું મેનુ લીલું-સોનેરી જ રાખ્યું છે. ગેમનાં ચિત્રો (મંદિર, મૂર્તિ-આકાશ, ગેલેક્સી, પડદો) એમ જ છે.
